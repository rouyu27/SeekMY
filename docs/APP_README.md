
  # SeekMY

  This is a code bundle for SeekMY. The original project is available at https://www.figma.com/design/MmG2o7bfWvLMUD3OHp3xww/YS---SeekMY.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  The project uses Firebase for Auth, Firestore, security rules and hosting. Supabase Edge Functions handle activity logs, reviews, leaderboard, weather and AI backend logic. See `BACKEND_SETUP.md` for setup and deployment instructions.
