State flag images
=================

Put flag pictures in this folder. If a file is missing, the app
uses the built-in SVG flag automatically.

Suggested filenames (PNG recommended, JPG/WebP also fine if you
rename in StateFlag.jsx):

  johor.png
  kedah.png
  kelantan.png
  melaka.png
  negeri-sembilan.png
  pahang.png
  perak.png
  perlis.png
  sabah.png
  sarawak.png
  selangor.png
  terengganu.png
  pulau-pinang.png
  kuala-lumpur.png
  labuan.png
  putrajaya.png

Path in the browser: /images/flags/johor.png
Code: src/components/StateFlag.jsx
